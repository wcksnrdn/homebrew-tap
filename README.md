# Homebrew Tap for flipfile

Official Homebrew tap for [flipfile](https://github.com/wcksnrdn/flipfile) — a fast, private, offline-first desktop file converter for macOS, Windows, and Linux.

## Installation

```bash
brew install wcksnrdn/tap/flipfile
```

Or tap manually:

```bash
brew tap wcksnrdn/tap
brew install --cask flipfile
```

## Update

```bash
brew upgrade flipfile
```

## Uninstall

```bash
brew uninstall --cask flipfile
```
